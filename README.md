### Torbjørn Svendsen

Data engineer, tech lead and team lead at Bouvet.
Building data platforms on Microsoft Fabric.

Previously statistician at Statistics Norway (SSB).
MSc Social Science, University of Bergen.

#### Selected Projects

- [medallion-template](https://github.com/tbsvendsen/medallion-template) — Reference implementation of medallion architecture for data pipelines. Polars, Pydantic v2, Kimball star schema with SCD type 2.
- [polars-pandas-duckdb-benchmark](https://github.com/tbsvendsen/polars-pandas-duckdb-benchmark) — Systematic performance comparison of three Python DataFrame engines across 9 operations.
- [duckdb-data-quality](https://github.com/tbsvendsen/duckdb-data-quality) — Data quality checks for DuckDB with typed Pydantic results and HTML reports.
